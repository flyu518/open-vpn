# OpenVPN 1.0.0 — 内部测试版

此草稿用于汇总同一源码候选的 Windows 与 macOS 安装包。平台可以按任意顺序将已安装验收的资产加入草稿；最终汇总工作流核对必需资产、源码候选和验收 SHA-256 后才会公开。

## 安装包

- `OpenVPN-1.0.0-windows-x64.exe`：Windows x64。
- `OpenVPN-1.0.0-macos-arm64.pkg`：Apple Silicon Mac。
- `OpenVPN-1.0.0-macos-x86_64.pkg`：可选；Intel 真机安装尚未验收，内部试用请按未验证资产对待。

## 内部使用限制

- 安装包没有完成正式发行签名/公证，Windows SmartScreen 或 macOS Gatekeeper 可能显示安全提示；仅通过团队认可的内部渠道分发。
- Windows 当前候选未做本轮安装后的重启验收；macOS 当前候选重装后未重做真实双隧道验收。已完成项目和未测项分别见两端验收记录。
- `SHA256SUMS` 与 `SOURCE-COMMIT.txt` 由最终汇总工作流根据草稿中的实际安装包生成；下载后应先核对哈希。

这不是面向公众的正式发行版，也不表示所有架构或所有 UI/系统生命周期场景均已验收。
